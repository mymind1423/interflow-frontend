# InternFlow - Frontend 🎨

Interface utilisateur moderne pour la plateforme InternFlow, construite avec React 19 et Tailwind CSS 4.

## 🚀 Technologies
- **React 19** : Hooks, Context API et Suspense.
- **Vite** : Bundleur ultra-rapide.
- **Tailwind CSS 4** : Design system moderne et utilitaire.
- **Framer Motion** : Micro-animations et transitions de pages.
- **Lucide React** : Librairie d'icônes cohérente.
- **React Router Dom** : Gestion de la navigation.
- **Firebase Auth** : Connexion et inscription sécurisées.

## 📦 Installation

1. Installez les dépendances :
   ```bash
   npm install
   ```

2. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

3. Pour builder en production :
   ```bash
   npm run build
   ```

## 🏗️ Structure du Projet
- `/src/components` : Composants réutilisables (Navbar, JobDrawer, Widgets...).
- `/src/pages` : Pages principales de l'application (Dashboard, Applications, Profile...).
- `/src/api` : Clients API pour communiquer avec le backend.
- `/src/authContext.jsx` : Gestion de l'état global de l'utilisateur.

## 💅 Design System
L'application utilise un **thème sombre forcé** (Slate 950) avec des accents bleus (Blue 600) et des effets de verre dépoli (glassmorphism).
